# ⚡ ЕНТ-Спринт: 80/20

Двуязычный (RU/KZ) сайт для подготовки к ЕНТ по принципу Парето:
**20% ключевых тем дают 80% результата**. Без регистрации, весь прогресс
в `localStorage` браузера. Mobile-first, светлая и тёмная темы.

## Запуск

Нужен только браузер + любой статический сервер (ES-модули не работают по `file://`):

```bash
# вариант 1: Node
npx serve .            # затем открыть http://localhost:3000

# вариант 2: Python
python -m http.server 8123   # затем открыть http://localhost:8123

# вариант 3: Windows PowerShell (без Node и Python)
powershell -ExecutionPolicy Bypass -File dev-server.ps1
# затем открыть http://localhost:8123
```

Либо откройте папку в VS Code и используйте Live Server.

## Структура

```

css/style.css            стили, light/dark через body[data-theme]
dev-server.ps1           локальный сервер для разработки (опционально)
js/
  config.js              ★ ФОРМАТ ЕНТ И ВСЕ НАСТРОЙКИ: задания, баллы, комбинации,
                         пороги поступления, очки/лиги, интервалы повторений
  app.js                 точка входа + hash-роутер (#/home #/sprint #/exam ...)
  ui.js                  переводы t(), язык, тема, toast, экранирование
  core/
    storage.js           состояние в localStorage (один ключ ent-sprint-v1)
    gamification.js      очки, стрик, штраф за пропуски, лиги, лог прогноза
    predictor.js         прогноз балла по весам предметов (20+10+10+40+40=120)
    rescue.js            калькулятор «Трек спасения»
    review.js            журнал ошибок + интервальные повторения (1/3/7/14 дней)
    exam.js              полный пробник: сборка 120 заданий, таймер 240 мин, проверка
  i18n/ru.js, i18n/kz.js ВСЕ тексты интерфейса по языкам
  data/
    subjects.js          реестр предметов (подключает файлы из subjects/)
    subjects/*.js        ★ по файлу на предмет: вопросы, карточки, совет
    resources.js         ссылки: только проверенные, остальные — «добавить вручную»
  pages/                 по файлу на страницу SPA
```

Звёздочкой (★) отмечены файлы, которые чаще всего нужно править при развитии.

## Формат ЕНТ (в js/config.js)

* 120 заданий, максимум 140 баллов, 4 часа.
* Обязательные: История Казахстана (20), Грамотность чтения (10), Математическая грамотность (10).
* Профильные: по 40 заданий каждый.
* 12 комбинаций + режим «Творческий экзамен» (без профильных, только советы и ресурсы).

Все цифры — настройки: поменяли спецификацию → поправили `EXAM`, `MANDATORY`,
`PROFILE_QUESTIONS`, `COMBOS` в `js/config.js`. Пороги поступления правятся и прямо
в интерфейсе (Профиль → Настройки), значения по умолчанию в `DEFAULT_THRESHOLDS`.

## Как добавлять контент

### Новый вопрос / карточка
Откройте `js/data/subjects/<предмет>.js`. Каждый вопрос:

```js
{
  id: 'mt-q11',                       // уникальный в рамках файла
  topic:  { ru: '...', kz: '...' },   // микро-тема для фильтров спринта
  text:   { ru: '...', kz: '...' },
  options:{ ru: ['A','B','C','D'], kz: ['A','B','C','D'] }, // ровно 4 варианта
  answer: 0,                          // индекс верного: 0=A, 1=B, 2=C, 3=D
  explain:{ ru: 'разбор на пальцах', kz: 'қарапайым талдау' },
  draft: true,                        // пока не сверено со спецификацией НЦТ
}
```

Карточка: `{ id, title:{ru,kz}, back:{ru,kz}, draft:true }`.

### Новый предмет
1. Скопируйте любой файл из `js/data/subjects/` как шаблон.
2. Поменяйте `id`, `icon`, `name`, контент.
3. Подключите его в реестре `js/data/subjects.js`.
4. Если предмет профильный и участвует в комбинациях — добавьте комбинацию
   в `COMBOS` (js/config.js).

### Новый ресурс
Добавьте объект в `js/data/resources.js` (см. комментарии).
Правило проекта: **ссылки только реально существующие**. Если точного адреса нет —
ставьте `url: null`: на сайте появится плашка «Ссылку добавить вручную».

### Переводы
Все строки интерфейса — в `js/i18n/ru.js` и `js/i18n/kz.js` (одинаковые ключи).

## Ссылки, которые нужно добавить вручную (url: null)

По состоянию на v1 точных публичных адресов для этих материалов нет — они
помечены в интерфейсе и ждут ручной вставки в `js/data/resources.js`:

| Где | Что нужно добавить |
|---|---|
| История Казахстана | утверждённый список исторических дат из спецификации НЦТ |
| Казахская литература | перечень литературных произведений (НЦТ) |
| Русская литература | перечень литературных произведений (НЦТ) |
| Физика | файл разрешённых справочных таблиц ЕНТ |
| Химия | файл разрешённых таблиц (периодическая, растворимость) |
| Иностранный язык | список лексики/грамматики по спецификации НЦТ |
| Все предметы | карточка «спецификация и тематический анализ» — точный URL PDF-спецификации текущего года |

Уже проверенные и включённые ссылки: `testcenter.kz`, `app.testcenter.kz`,
`prob-ent.testcenter.kz` (бесплатные пробные тесты НЦТ), `edunavigator.kz`.

## ⚠️ Черновик контента

В v1 на каждый предмет — 10 вопросов и 5 карточек **примерного** содержания.
Они помечены `draft: true` и в интерфейсе показываются с плашкой
«Черновик — проверьте по спецификации НЦТ». Перед публичным использованием
сверьте каждый вопрос с официальной спецификацией и тематическим анализом НЦТ.

## Технологии

Vanilla JS (ES-модули), без сборщика и зависимостей. Данные — обычные JS-файлы
(`export default {...}`): их можно держать в JSON-подобном виде и по желанию
перевести в fetch-загрузку `.json` без изменения логики страниц.
